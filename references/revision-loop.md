## 1. 返修总流程
1. **时间轴是上一版成片的**。用户说“3:10”，指的是她刚看的那版成片，不是源片。先用 `scripts/map_timeline.py --edl rough_cut_v{n-1}_edl.json --at 3:10 --window 3` 换算回 EDL 段和源片秒数。
2. **用户报的时间常偏晚约 1.7–2 秒**（看到问题、暂停、再读时间）。在报点前后 ±3 秒内找对应的切点或内容。
3. **区分两类问题**：
   - 报点附近有切点：问题多半在切点本身（太紧、残音、动作跳变）。
   - 附近没有切点：问题在连续口播内部（重复、空停、动作），要对照转录和画面找。
4. **找不到对应内容就不乱改**：说明“该处是连续口播 X，±3 秒内没有切点/重复”，回报让用户确认更准的位置。宁可一处不改，也不要瞎删。
5. **有歧义先问**：例如“最后 28 秒往后移 5 帧”，既可理解为离结尾 28 秒处的切点，也可理解为片尾出点。这次实际是“结尾切太快”。拿不准时，先按最直接的理解做，同时在报告里写明另一种理解，请用户确认。
6. 在上一版 EDL 基础上改，存 `rough_cut_v{n}_edl.json`；没被点到的地方保持不动。每段 reason 追加 `｜v{n}: …`。
7. 渲染成新文件 `粗剪第{n}版.mp4`，旧版全部保留。
8. 报告每一处：上一版的实际时间、源片改动区间、删了什么，以及**新版里的复查时间点**（用户下一轮会按新版时间看）。

## 2. 用户常用说法对照表

| 用户说 | 实际含义 | 做法 |
|---|---|---|
| “气口往后移一点”“衔接自然一些” | 切点太紧，句尾或换气被切 | 在静音里给出点多留 0.2–0.4s 尾音，或把入点提前留出开口前停顿；不能挪进相邻的废句 |
| “X 秒往后移 N 帧” | 某个出/入点挪 N/30 秒 | 先确认是哪个点；“最后/结尾”相关的多半是片尾出点太紧 |
| “结尾切太快” | 片尾卡在末字上 | 最后一段出点往后 0.15–0.5s，先确认那段是静音、没有杂音或新口播 |
| “多余动作”“扶眼镜”“抿嘴”“按屏幕”“手势打出来没说话” | 无口播的动作段 | 音量曲线找静音 + 逐帧找动作起止，把整段切掉 |
| “空的切干净”“停顿了没说话” | 句中长空停（>1s） | 删掉静音段，前后各留 0.15–0.2s |
| “有点顿” | 切点残留上一遍的尾音再空停，或切点前后空停过长 | 入点越过残音，收紧空停 |
| “A。A 看起来…重复了”“说了两遍” | 失败起句 / 重说 | 对照词级时间戳删前面不完整的一遍，留最后完整的一遍 |
| “说了你们，然后…所以你…” | 失败起句 + 动作 + 停顿，后面重说完整句 | 用户复述的词可能是 ASR/听感误差（“你的身”听成“你们”），以重转结果为准，从完整句接上 |

## 3. 精修技术：音量曲线 + 逐帧拼图
动作类和停顿类问题不能只靠转录，转录看不到画面，VAD 也会抹掉短停顿。

**音量曲线**：`scripts/probe_window.py --media <wav或MOV> --start a --end b`，每 50ms 一个 dBFS 值。
- 说话约 −30~−45 dB；静音/底噪约 −70 dB；−50~−60 是字头字尾或轻声，不能当静音切。
- 轻声的整句可能只有 −45~−50 dB，ffmpeg silencedetect（−35dB）会误判成静音；以曲线和重转结果为准。

**逐帧拼图**：`scripts/probe_window.py --media 3.MOV --start a --end b --sheet x.png`（默认 10fps，10 列，160px 宽，每格标源片秒数）。
- 素材在用户电脑上时，在用户电脑上抽拼图，存到 Documents 下，再 CopyToBox 回来，用 Read 看图。
- 看什么：嘴是否在动、手何时抬起/放下、是否扶眼镜/碰屏幕、身体是否静止。确定动作起止到 0.1s。
- 拿不准时可在关键 0.5s 内改用 30fps 逐帧再看。

## 4. 切点规则
- 切点落在静音里：出点 = 末字结束 + 0.15–0.2s，入点 = 开口 − 0.15–0.2s。
- 删除区间 = [上一句末字后约 0.15s, 下一句开口前约 0.15s]。
- 手势与开口同时发生时，优先不切字，保留手势，在报告里说明。
- 硬切两侧手位/姿态不同会有跳变（比如一边手放下、一边手举着），这是素材限制，报告里提示，用户可在精剪时用 B-roll 或缩放遮掉。
- 片尾出点留尾音前，先确认后面那段是静音（约 −60 dB 以下），没有杂音或新口播。
- 没把握的地方不改，写进未确认项。

## 5. 交付报告模板

```
## 成片
- 路径：…\粗剪第N版.mp4
- 时长：xxx.xx s（EDL 合计 xxx.xx s，误差 0.xx s）
- 规格：1080×1920 H.264 30fps / AAC 48kHz 立体声，完整解码 pass；硬切 K 段
- EDL：…\粗剪工作区\rough_cut_vN_edl.json（box 副本 …）
- 旧版：第 1…N-1 版均保留未覆盖

## 改动
| # | 用户报点 → 上版实际位置 | 源片区间（片段/秒） | 删了/挪了什么 | 新版复查时间 |
|---|---|---|---|---|

## 未确认 / 没把握
- 找不到对应内容的报点、歧义理解、手位跳变、可能仍可见的动作等
```
