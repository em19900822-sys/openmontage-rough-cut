# 实战案例：10.25 多囊口播（四段 MOV → 四版返修）

素材：用户 Windows 电脑 `D:\Obsidian\新建文件夹\10.26视频\10.25\1–4.MOV`（1080×1920，30fps，合计约 832s，大小 137–228MB），顺序拍摄、每段开头报段号。飞书精修稿只作对齐参考。成片输出到 `…\10.26视频\粗剪第一版\粗剪第{n}版.mp4`，EDL 放在 `…\粗剪工作区\`。

| 版本 | 时长 | 段数 | 要点 |
|---|---|---|---|
| v1 | 628.47s | 30 | 删段号口令、重复句、失败起句（约 204s） |
| v2 | 618.80s | 31 | 两处切点留气口；删 9:25 附近 VAD 漏掉的三遍重复 |
| v3 | 618.97s | 31 | 片尾出点 +5 帧（结尾切太快） |
| v4 | 602.27s | 37 | 10 处精修：失败起句、无声动作、长空停、残音 |

## v1 → v2 的教训
- 0:25 和 3:12 两处 ±3s 内没有切点，都是连续口播，所以没改，回报给用户确认。之后用户在 v3 意见里讲清楚了：0:24 是“哪怕/生怕”失败起句，3:10 是“周期。周期看起来”的重复。**说明 v1 就该把这类短失败起句删掉，且回报“未找到”是对的。**
- 0:59、8:28 两处实际切点在 0:57.34、8:26.08，用户报的时间晚约 1.7–2s。
- 9:25 附近：VAD 版转录只有“才慌慌张张的 / 往考场里面去赶”（“场”字被拉到 3.6s）。关掉 VAD 重转后，看出 4.MOV 87.5–102.8s 是同一句“不要等泡泡都排出来了，才慌慌张张…”说了三遍；删前两遍（87.45–97.45s）。
- “最后 28 秒往后移 5 帧”：先按离结尾 28 秒最近的切点做了，用户澄清后才知道是片尾太紧。**有歧义应先问或两种都说明。**

## v3 → v4 的 10 处（时间为 v3 成片 → 源片删除区间 → v4 复查点）
1. 0:22.3 “哪怕”失败起句 → 1.MOV 23.85–25.00 → 0:21.88
2. 0:57.3 切点两侧抬手/举手静止 → 1.MOV 段尾 62.10–62.39 + 段首 64.45–64.80 → 0:55.90（两侧手位不同，有跳变）
3. 1:47–1:49 “较劲”后 2.1s 静止 → 1.MOV 121.40–123.47 → 1:45.56
4. 2:38 “有点顿”：入点 190.91 带进了上一遍“…显示出”的残音再空停 → 入点改为 191.22，前一段出点 188.51 → 188.70 → 2:34.53
5. 3:10 “周期。周期看起来” → 2.MOV 22.05–23.08 → 3:05.78
6. 4:18–4:22 “那”+扶眼镜+双手扶脸 3.9s → 2.MOV 101.12–104.97 → 4:13.58
7. 6:40 “扎根”后 1.3s 空停 → 3.MOV 68.62–69.88 → 6:31.35
8. 6:57–6:59 抿嘴+停顿+双手扶眼镜 → 3.MOV 89.47–92.08 → 6:46.69（新入点时手仍在放下）
9. 7:07–7:10 用户听成“你们”的其实是失败起句“你的身…”，之后手去按屏幕、停顿 3.4s，再说完整句“你的身体是比狮子要聪明一万倍的” → 3.MOV 103.28–106.90 → 6:53.65（用户说的“所以你”转录里没有，以重转为准）
10. 9:32 开口前 0.4s 静止，手势与开口同时 → 入点 97.45 → 97.83，手势保留不切字 → 9:15.28

## 可复用的数字
- 本素材说话 −28~−45 dB，底噪 −70~−75 dB，轻声句 −45~−50 dB（silencedetect −35dB 会误判）。
- 切点两侧气口取 0.15–0.2s；片尾 +0.167s（5 帧）后确认仍是 −60 dB 静音。
- 约 10 分钟成片，libx264 在用户笔记本上渲染 6–8 分钟。
